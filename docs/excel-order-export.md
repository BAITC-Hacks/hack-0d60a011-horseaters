# Excel-экспорт заказа для 1С (проектный шаблон MVP)

Это выбранный проектом формат обмена, а не универсальный формат 1С. На стороне
конкретной конфигурации 1С нужно настроить импорт листа `Заказ`: сопоставить
поставщика и склад по наименованию, номенклатуру по артикулу, количество взять
из `Утверждённое количество`. Если имена не уникальны, их нужно заранее
сопоставить со справочниками 1С; до такого сопоставления автоматическую загрузку
считать подтверждённой нельзя. Передача поставщику автоматически не выполняется.

Файл формируется в формате `.xlsx`, один заказ — один плоский лист `Заказ`.
Порядок колонок является частью контракта и не меняется без отдельной версии формата:

1. `Номер заказа`
2. `Поставщик`
3. `Склад`
4. `Артикул`
5. `Наименование`
6. `Рекомендованное количество`
7. `Утверждённое количество`
8. `Цена`
9. `Сумма`
10. `Дата поставки`

Объединённые ячейки не используются. Количества, цена и сумма записываются как
числовые значения Excel, дата поставки — как дата Excel с отображением
`ДД.ММ.ГГГГ`. Дата поставки рассчитывается от даты утверждения заказа с учётом
срока поставки по условиям поставщика.

Контрольный файл: [`examples/order-export-1c.xlsx`](examples/order-export-1c.xlsx).
